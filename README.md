Welcome to my website source code!

Check it out at [kw-m.cc](https://kw-m.cc)


### Sveltekit

To recreate this project with the same sveltekit configuration:

```sh
pnpm dlx sv@0.16.3 create --template minimal --types ts --add tailwindcss="plugins:typography,forms" mdsvex sveltekit-adapter="adapter:static" mcp="ide:vscode,claude-code+setup:local" --install pnpm portfolio
```
